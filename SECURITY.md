# Security Policy

## Supported Versions
This project is under active development. Security fixes (if any) will be applied to the `main` branch.

## Reporting a Vulnerability
If you discover a security vulnerability, please do **not** open a public GitHub issue.

Instead, report it privately:
- Email: **seanousv@gmail.com**
- Subject: **[SECURITY] seano-collision-avoidance**

Please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Impact assessment (what could happen)
- Any logs, screenshots, or proof-of-concept (if safe to share)

## Response Timeline
We will acknowledge receipt as soon as possible and work on a fix based on severity and available resources.

## Disclosure Policy
We prefer responsible disclosure. Please allow time for a fix to be prepared before sharing details publicly.
